Guided run — easy mode

One step at a time: ears on, sound check, headband, signal check, then the session runs itself and tells you when it's done. Use this instead of the controls below whenever you just want to run it.

Stimulus

Run the stereo check with the exact headphones you will wear: LOW tone in the LEFT ear only, then HIGH tone in the RIGHT ear only. If either tone reaches both ears (mono Bluetooth profile, Windows mono-audio toggle, spatial sound), the binaural condition degrades into an ordinary audible beat and the run is void. Wired closed-back headphones at modest volume are the safe choice.

Protocol

Block order is shuffled at start. 4 conditions × 6 repeats × ~3.3 min ≈ 80 minutes; run a pilot with 2 repeats first. Eyes closed, seated, still. Minimum 90 s per block so wPLI has ≥ 8 clean 16 s windows. The artifact threshold in Settings governs which windows are dropped.

Pipeline self-test (Simulate mode)

With Simulate running and this ON, a run must show elevated dwPLI and SNR on binaural and isochronic rows and nothing on pure/silence. With it OFF, every row must be null. Passing both is the difference between “no effect” and “broken pipeline”.

Import a Mind Monitor recording

Workflow: connect the headband in Mind Monitor (its native connection is the reliable one), start its recording, run the sound session, stop, and open the exported CSV here. Set Δ to the beat the sound used — Entrainment Lab shows it big on its screen. The file is read on this device only; nothing is uploaded. Mind Monitor must have RAW data enabled in its recording settings (it is by default).

Session detail

Signal processing

The notch matters more than people expect — mains hum leaks into the gamma band and will quietly inflate any gamma-based metric. Leave it on unless you are specifically inspecting it.

Device

If the headband connects but no data arrives, try p20. Firmware revisions differ in which presets they accept, and a rejected preset fails silently.

Notes

Electrode order: TP9 (left ear), AF7 (left forehead), AF8 (right forehead), TP10 (right ear), at 256 Hz. Raw values are 12-bit, converted with (counts − 2048) × 0.48828125 to give µV.
Contact: the ear electrodes are the usual culprit. Wet them slightly and make sure hair is out of the way — the quality chips at the top right go green when a channel settles.
This is not a medical device. Consumer EEG at four dry electrodes is fine for training and curiosity, and cannot diagnose anything.
